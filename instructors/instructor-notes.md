This is the first tutorial in the EIC series and establishes the environment (`eic-shell`) and
collaboration tools (GitHub) that every later tutorial depends on.

## Before the session

- Ask learners to complete the [Setup](../learners/setup.md) page in advance: downloading the
  container can take a long time on systems without `/cvmfs` (up to ~13 GB), so it should not be
  done live.
- Confirm learners have a GitHub account and, ideally, membership of the
  [EIC organization](https://github.com/eic).

## Timing

The lesson is short (~30 minutes of teaching). Most of the wall-clock time is the container
download, which learners should have done beforehand.
